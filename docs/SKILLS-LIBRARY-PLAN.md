## Видение

ProektMap = библиотека профессиональных Skills для Reasonix-экосистемы.

Каждый публичный Skill одновременно:
- Делает полезную работу (ценность для пользователя Reasonix)
- Демонстрирует методологию ProektMap (маркетинг)
- Ведёт на платформу (воронка: Skill → ProektMap → Pro)

---

## Два типа Skills в ProektMap

| | Prisma Skill (БД) | Reasonix Skill (`.reasonix/`) |
|---|---|---|
| **Для кого** | Человек (обучается) | AI-агент (выполняет) |
| **Формат** | Запись в БД + SKILL.md | Файл SKILL.md + frontmatter |
| **Где живёт** | `/admin/skills` | `.reasonix/skills/` |
| **Пример** | «Настройка ESLint» (XP, шаги) | `visual-content` (процедура) |
| **Монетизация** | Pro-подписка, XP | Бесплатно (promo) |

Это не дублирование — это два слоя одной экосистемы.

Мост между ними: Prisma Skill описывает «что делать», Reasonix Skill выполняет «как делать».

## Система доверия: три уровня проверки

> **Проблема:** исследование 2026 года показало дефекты у 91,8% Skills в публичных каталогах.
> Обнаружены вредоносные Skills, ворующие SSH-ключи, токены Git, Docker-конфигурации и credentials.
> Вопрос завтрашнего дня: не «где найти Skill», а «какому Skill можно доверять».
> **Позиция ProektMap:** не океан Skills, а навигатор по проверенным.

### Уровни

| Уровень | Метка | Критерии |
|---------|-------|----------|
| 🟢 **Проверен ProektMap** | `verified` | Ручная проверка кода, нет сетевых запросов к сторонним хостам, нет доступа к secrets, протестирован с Reasonix / Cursor / Claude Code, автор подтверждён |
| 🟡 **Community** | `community` | Новый Skill, ещё не прошедший полную проверку. Код доступен, автор известен, нет явных угроз |
| 🔴 **Не рекомендуется** | `flagged` | Обнаружены подозрительные команды, сетевые запросы к неизвестным хостам, попытки доступа к secrets, обфускация |

### Процесс проверки

1. **Автоматическая:** сканирование на подозрительные паттерны (shell exec, network requests, file read из敏感ных директорий)
2. **Ручная:** аудит кода экспертом ProektMap
3. **Community:** отзывы и репорты от пользователей
4. **Периодическая:** повторная проверка при обновлениях

### Критерии для 🟢 Проверен ProektMap

- [ ] Код полностью открыт и читаем
- [ ] Нет `curl`, `wget`, `fetch` к неизвестным хостам
- [ ] Нет доступа к `.ssh/`, `.git/config`, `.env`, `credentials`
- [ ] Нет `eval`, `exec` с динамическим кодом
- [ ] Все внешние зависимости зафиксированы (версии, хеши)
- [ ] Протестирован минимум с 2 AI-агентами
- [ ] Автор подтвердил личность (GitHub, Telegram)
- [ ] Есть документация на русском языке

## Принципы разработки Skills

1. **Самодостаточность.** Skill полезен даже без ProektMap.
2. **Одна задача.** Skill делает одну вещь и делает её хорошо.
3. **Русский язык.** Все Skills на русском (целевая аудитория — РФ).
4. **Ссылка на ProektMap.** Каждый Skill содержит «Узнать больше → proektmap.ru/...»
5. **Не AI-сток.** Избегаем шаблонных решений, используем оригинальную методологию.

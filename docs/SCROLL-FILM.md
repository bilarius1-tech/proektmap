## Что это

**Scroll-лендинг / «сайт-фильм»** — страница, где скролл пользователя управляет непрерывной анимацией (таймлайном), как пульт камеры в фильме. Не набор статичных блоков «прочитал и дальше», а **одна сцена с несколькими кадрами**.

Типичный пайплайн продакшна у агентств:

1. Согласовать ~5 сцен (раскадровка).
2. Сгенерировать / снять видео **или** собрать анимацию в коде.
3. Привязать прогресс скролла к таймлайну.

## Как работает технически

```
ПОЛЬЗОВАТЕЛЬ СКРОЛЛИТ
        ↓
Scroll position (0…1)
        ↓
Animation timeline (GSAP)
        ↓
┌─────────────────────────┐
│ Scene 1  появление/zoom │
│ Scene 2  камера дальше  │
│ Scene 3  смена объекта  │
│ Scene 4  новый ракурс   │
│ Scene 5  CTA / форма    │
└─────────────────────────┘
```

Скролл → `progress` → кадры (opacity / transform / stagger).

### Три подхода (выбор стека)

| Подход | Суть | Когда брать |
|--------|------|-------------|
| **Video scrub** | Скролл крутит видео по кадрам | Киношный реализм, дорогой продакшн |
| **Three.js / R3F** | Настоящая 3D-камера | Нужен объём «в пространстве» |
| **HTML/CSS + GSAP** | DOM, transform, opacity | Быстрый коммерческий прототип |

**Для ProektMap сейчас выбран третий:** без Three.js, без тяжёлого видео.

## Стек нашего демо

| Слой | Технология |
|------|------------|
| Фреймворк | Next.js 16 (App Router) + React 19 + TypeScript |
| Анимация | **GSAP** + **ScrollTrigger** (`scrub`) |
| Smooth scroll | **Lenis** (синхронизация с `gsap.ticker`) |
| Иконки | `lucide-react` |
| Стили | inline styles + бренд `#0FB880` (как в остальном проекте) |

Зависимости в `package.json`: `gsap`, `lenis`.  
Установка на этом репо: `npm install … --legacy-peer-deps` (из‑за peer-конфликтов tip-tap).

## Как развивать дальше

1. **Офферный лендинг** — заменить демо-тексты под конкретный продукт/квест, оставить механику.  
2. **Боевая форма** — API → Telegram bot / CRM.  
3. **Video scrub** — если нужен «кино»-уровень (тяжёлые файлы, preload, мобилка).  
4. **Three.js** — только если псевдо-3D на DOM недостаточно.  
5. **Доступность** — кнопка «пропустить фильм» / обычная версия страницы.  
6. **Мобилка** — короче runway (`height`), меньше параллакса; сейчас тяжёлые карточки на узких экранах скрыты CSS.

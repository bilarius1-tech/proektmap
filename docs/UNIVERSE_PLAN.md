### v2.0 — AI-генерация вселенной (3-5 дней)

```
Пользователь: «Маркетплейс фермерских продуктов»
                    ↓
              AI (GigaChat)
                    ↓
         ┌──────────┼──────────┐
         ▼          ▼          ▼
     🌞 Звезда   🪐 Планеты  🛤 Маршруты
    (бизнес)   (направления) (связи)
```

| Компонент | Описание |
|-----------|----------|
| **AI-анализатор** | `/api/universe/generate` — принимает описание, возвращает JSON-граф |
| **Солнечная система** | Центральная звезда = бизнес, планеты = направления, спутники = задачи |
| **Анимация рождения** | Частицы собираются → формируют узлы → появляются орбиты |
| **Прогресс-бар** | «AI анализирует...», «Строит вселенную...», «Прокладывает маршруты...» |

**API-контракт:**
```json
POST /api/universe/generate
{ "idea": "Маркетплейс фермерских продуктов" }

→ {
  "star": { "name": "Фермерский Маркетплейс", "color": "#0FB880" },
  "planets": [
    { "name": "Каталог товаров", "orbit": 1, "tasks": ["Фото", "Категории"] },
    { "name": "Платежи", "orbit": 2, "tasks": ["ЮKassa", "Чеки"] },
    { "name": "Логистика", "orbit": 3, "tasks": ["Доставка", "Трекинг"] }
  ],
  "routes": [
    { "from": "Каталог товаров", "to": "Платежи", "label": "заказ" }
  ]
}
```

### v3.0 — Режимы отображения (5-7 дней)

| Режим | Визуализация | Для кого |
|-------|-------------|----------|
| 🌌 **Universe** | Галактика, звёзды, туманности | Wow-эффект, вирусный контент |
| 🏙️ **City** | Изометрический город, кварталы = модули | Инвесторы, понятно |
| 🏢 **Corporation** | Орг-схема, департаменты, этажи | B2B, консалтинг |

### v4.0 — Живая вселенная (10+ дней)

```
Пользователь принимает решение в Blueprint
        │
        ▼
   Вселенная реагирует:
   · Загорается новая звезда
   · Появляется маршрут к планете
   · Растёт дерево зависимостей
```

**Интеграция с Blueprint:**
- Каждый пройденный Decision = +1 звезда в системе
- Каждый Stage = новая орбита
- Завершённый Blueprint = сверхновая ✨

## 🏆 Убийственная демка (для конкурса/инвесторов)

### «Опиши бизнес — смотри как рождается вселенная»

**Страница:** `/universe/demo`

1. Поле ввода: «Какой бизнес хочешь создать?»
2. Кнопка: «🌌 Создать вселенную»
3. Анимация: частицы → звезда → планеты → маршруты (15 сек)
4. Результат: интерактивная 3D-вселенная бизнеса
5. Кнопка: «Пройти Blueprint →»

**Почему это победит:**
- Никто из конкурентов (ProtoMap, ProdMap, AI Manual) не делает **интерактивный 3D-мир из бизнес-идеи**
- Это не «ещё один AI-лендинг», а **новая форма взаимодействия с AI**
- Вирусный потенциал: «Посмотри как AI построил вселенную для моего бизнеса»

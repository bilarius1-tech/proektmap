## Два слоя

- **DNA** — философия, AGENTS, Cursor rules, skills, Harness/Loop/Graph, DoD, промпты, решения (`dnaVersion`, `derivedFrom`)
- **Snapshot** — код, schema, infra configs, `.env.example`, SECRETS.md (имена), URL/VPS metadata

**Client Boundary** по умолчанию: без PII, без секретов, без customer DB.

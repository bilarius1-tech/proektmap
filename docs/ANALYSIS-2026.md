# Анализ проекта ProektMap — 2026

## 1. Обзор проекта

### 1.1. Суть проекта
ProektMap («Карта роста») — образовательная платформа для обучения AI-инжинирингу. Главный принцип: «Сначала думаем — потом строим» (Decision-Driven Development). Платформа не учит копировать промпты, а развивает инженерное мышление.

Пользователь проходит Blueprint (карту проекта), принимает решения на каждом этапе, фиксирует свой выбор и причины. На выходе получает полный бриф проекта, готовый к передаче AI-агенту для реализации.

### 1.2. Технологический стек
- Frontend:  Next.js 16 + React 19 + TypeScript
- Backend:   API Routes Next.js + Prisma 7 ORM
- БД:        PostgreSQL
- Стили:     Tailwind CSS 4 установлен, но используется inline-styles
- Редактор:  TipTap (14 расширений, таблицы, видео, изображения)
- Графы:     React Flow (визуализация схем)
- Иконки:    Lucide React
- Анимация:  Framer Motion
- PDF:       jsPDF
- Auth:      NextAuth (Yandex OAuth + email/пароль)
- Платежи:   ЮKassa (300 руб/мес Pro)
- AI:        DeepSeek + OpenRouter
- Деплой:    PM2 (порт 3030) + nginx, ручной через SCP

## 2. Сильные стороны проекта
================================================================================

### 2.1. Уникальная методология
Decision-Driven Development — это не просто курс, а система принятия решений. 12-польная структура Decision заставляет пользователя думать как инженер. Конкуренты (easy-vibe, ai-guide) дают готовые промпты; ProektMap учит думать самостоятельно.

### 2.2. Чёткая философия и позиционирование
Документированная философия (PHILOSOPHY.md, MANIFEST.md, METHODOLOGY.md). Понятная целевая аудитория: вайбкодеры, переросшие Tilda/WordPress.

### 2.3. Богатая контентная база
113 терминов глоссария, 31 AI-инструмент, 122 связи в графе, 80+ решений в 3 активных Blueprint'ах. Это уже ценный справочный ресурс.

### 2.4. Гибкая админка
Управление контентом через веб-интерфейс, а не только через seed-файлы. Редактирование Blueprint'ов, решений, настроек сайта.

### 2.5. AI-интеграция
AI-Архитектор, AI-улучшение текстов блога, fallback DeepSeek -> OpenRouter. Платформа использует AI для усиления, а не замены мышления.

### 2.6. Активная разработка
388 коммитов, регулярный DEVLOG, документация высокого качества (21 файл в docs/). Проект живой и развивается.

## 3. Проблемы и уязвимые места
================================================================================

### 3.1. КРИТИЧЕСКИЕ

**[A] Утечка учётных данных в репозитории** — ИСПРАВЛЕНО
    AGENTS.md содержал email и пароль администратора в открытом виде.
    Решение: строка заменена на заглушку, пароль необходимо сменить.

**[B] 3 из 6 Blueprint'ов полностью пусты** — ИСПРАВЛЕНО
    По состоянию на август 2026: 11 Blueprint'ов с контентом, пустые скрыты (isPublished=false).

**[C] Отсутствие автоматизированного тестирования** — В РАБОТЕ
    В package.json нет test-скрипта. Нет jest, vitest, playwright.
    Баг с globals.css (3 дня правок не работали из-за отсутствия импорта) — прямой результат отсутствия тестов.
    Рекомендация: Внедрить минимум smoke-тесты для ключевых страниц и API-эндпоинтов.

### 3.2. ВЫСОКОГО ПРИОРИТЕТА

**[D] Инлайн-стили вместо Tailwind**
    Tailwind CSS 4 установлен, но весь UI использует inline styles.
    Рекомендация: Постепенный переход на Tailwind-классы.

**[E] Ручной деплой через SCP**
    Нет CI/CD. Деплой = ручная загрузка файлов на сервер.
    Рекомендация: GitHub Actions для автодеплоя.

**[F] Отсутствие аналитики пользователей**
    Нет tracking-системы (Yandex.Metrica уже установлена — см. счётчик на сайте).
    Рекомендация: Настроить цели в Metrica.

**[G] Русскоязычная локализация только**
    Весь интерфейс и контент на русском. Рынок ограничен РФ/СНГ.
    Рекомендация: Подготовить i18n-инфраструктуру.

### 3.3. СРЕДНЕГО ПРИОРИТЕТА

**[H] Solution Library не реализована**
    Статус — запланировано. Модель Solution есть в схеме БД.
    Рекомендация: Внедрить Фазу 1 (сохранение + страница).

**[I] Монетизация ограничена одной подпиской**
    Только Pro 300 руб/мес. Нет разовых покупок, командных тарифов.
    Рекомендация: Добавить Team, Lifetime, Premium Blueprint.

**[J] Нет email-маркетинга**
    Нет рассылок, welcome-цепочек.
    Рекомендация: Интегрировать email (nodemailer уже есть).

**[K] Нет мобильной оптимизации в приложении**
    Нет PWA, нет мобильного приложения.
    Рекомендация: PWA-манифест, offline-режим.

**[L] Качество кода: hydration-ошибки**
    suppressHydrationWarning на body — косметическое решение.
    Рекомендация: Систематически исправить hydration-проблемы.

**[M] Премиум-Blueprint'ы пусты**
    Страница /blueprints-premium существует, но без контента.
    Рекомендация: Наполнить или скрыть до готовности.

## 6. Конкурентный анализ
================================================================================

### 6.1. Прямые конкуренты
| Платформа    | Подход                  | Слабость                    |
|--------------|-------------------------|-----------------------------|
| easy-vibe    | Готовые промпты         | Нет мышления, только копипаст|
| ai-guide     | Личный опыт             | Субъективно, не системно     |
| ProektMap    | Методология (думай сам) | Требует усилий от пользователя|

### 6.2. Конкурентное преимущество
ProektMap — единственная платформа, которая учит ИНЖЕНЕРНОМУ МЫШЛЕНИЮ, а не даёт готовые решения. 12-польная структура Decision уникальна. Бриф на выходе — tangible value, которого нет у конкурентов.

### 6.3. Риски
- Появление аналогов с AI-генерацией решений (низкий барьер)
- Бесплатные альтернативы (YouTube, блоги)
- Скорость заполнения контента
- Одноязычность (только русский)

## 8. Итоговая оценка
================================================================================

Проект ProektMap обладает сильным концептуальным фундаментом и уникальной методологией Decision-Driven Development. Качество документации и глубина проработки философии выгодно отличают проект от конкурентов.

По состоянию на август 2026: 11 активных Blueprint'ов, критические проблемы [A] и [B] исправлены. Основной фокус: тестирование, CI/CD, Solution Library, монетизация.

Потенциал проекта высокий. Рынок AI-образования в РФ растёт. При дисциплинированном выполнении плана ProektMap может стать ведущей русскоязычной платформой для обучения AI-инжинирингу в течение 6 месяцев.

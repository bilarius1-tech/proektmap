# ТЗ: «Лаборатория Авито» — каталог инструментов Авито

> **Статус:** 🟡 ПЛАН (18.08.2026)
> **Дата:** 18.08.2026
> **Цель:** собрать программы, сервисы и браузерные расширения для работы с Авито в одном месте; рейтинг ставят авитологи по реальному опыту, а не ProektMap.
> **Принцип:** «2ГИС / IMDb для инструментов Авито». Мы не решаем, какой сервис лучший, — мы собираем и даём оценить сообществу.

## 1. Продукт

| | |
|---|---|
| URL | `/avito` (страница-хаб, как `/telegram`) |
| Название | «Лаборатория Авито» |
| Позиционирование | «Не знаешь, какой сервис выбрать? Посмотри, чем пользуются другие авитологи.» |
| Язык | RU |
| Стек фазы 1 | статичный каталог: данные в TS-файле (паттерн `resheniya/guided-data.ts`) |
| Стек фазы 2 | Prisma (5 сущностей) + авторизация |
| Дизайн | inline styles, Lucide-иконки, шрифт Inter (как весь ProektMap) |
| Не делаем | ProektMap Score, рой агентов, Evidence с confidence, отдельный сайт |

**Критерий успеха:** авитолог (или продавец) заходит, за минуту находит нужный инструмент и видит, что им реально пользуются люди.

## 2. Два этапа (главное — холодный старт)

Рейтинг авитологов работает, только если есть авитологи. Сейчас их на ProektMap ноль, поэтому:

**Фаза 1 (MVP, без БД)** — каталог, полезный сам по себе, без единой оценки:
- 10–20 сервисов из master-list, проверенных вручную;
- карточки + категории + поиск + фильтры;
- поле «дата последней проверки + статус» (работает / умер / сменил тариф);
- рейтингов НЕТ (пустая доска хуже, чем её отсутствие).

**Фаза 2 (после аудитории)** — коллективный опыт:
- «Рейтинг авитологов» (5 вопросов);
- отзывы;
- «Мой стек авитолога» (публикация + подписка).

Фаза 2 включается, когда есть трафик или приведены первые авитологи.

## 4. Карточка инструмента (фаза 1)

```
Название (AvToolsPro)
Тип: Расширение · Категория: Аналитика
Краткое описание (1–2 строки)
Цена: от 0 ₽
Статус: ✅ работает · проверено 18.08.2026
Бейдж: «официальный Avito API» или «⚠ риск блокировки» (парсинг/мультиаккаунт)
Ссылки: сайт · расширение
```

**Обязательно:** серую зону не прятать — «Парсинг» и часть «Автопостинга» нарушают правила Авито. Бейдж «⚠ риск блокировки» — честность, а не минус.

## 5. Рейтинг авитологов (фаза 2)

Оценка — 5 простых вопросов, не форма:
1. Насколько полезен? ⭐ 1–5
2. Насколько удобен? ⭐ 1–5
3. Стоит своих денег? ⭐ 1–5
4. Порекомендовали бы коллегам? ⭐ 1–5
5. Пользуетесь сейчас? Да / Нет
+ поле «Что понравилось / не понравилось».

Средний рейтинг считается автоматически. Производные: «X оценок», «Y% продолжают пользоваться», рейтинг по задачам (лучшие для аналитики / парсинга / AI / бесплатные / новичок).

**«Мой стек авитолога»:** «Работаю с Авито 7 лет, вот мой стек» → публичный стек (аналитика + парсинг + AI + дизайн + автопостинг), другие смотрят и подписываются.

## 7. Агент-исследователь (один, не рой)

На старте один агент:
- «Найди сервисы аналитики Авито» → добавляет кандидатов, **человек проверяет**.
- «Проверь этот сервис» → собирает: название, сайт, описание, категорию, цену, ссылку, тип.
- Раз в неделю обновляет «дата проверки + статус» (работает / умер / сменил тариф).

Рейтинг ставят **люди**, не агент. Агент не выставляет оценки.

## 8. Критерии «готово» — фаза 1

- [ ] `/avito` открывается на проде
- [ ] 10–20 сервисов с карточками (проверены вручную)
- [ ] категории + поиск + фильтры работают
- [ ] у каждой карточки slug + SEO title/description (long-tail)
- [ ] «дата проверки + статус» отображается
- [ ] бейдж «⚠ риск блокировки» у парсеров/мультиаккаунтов
- [ ] нет «стены текста», нет эмодзи-каши
- [ ] build + `pm2 restart proektmap` без ошибок

**Вне скоупа фазы 1:** рейтинг/отзывы/стеки, Prisma-модель, агент (можно вручную), admin-интерфейс.

---

## 9. Порядок реализации

1. Скелет `/avito` + TS-файл данных (10–20 сервисов, вручную проверенные)
2. Карточки + категории + поиск + фильтры
3. SEO (slug, title, description; каталог + при желании `/avito/[slug]`)
4. Проверка на реальном телефоне (mobile-first, как остальной сайт)
5. Фаза 2 — только после трафика/аудитории

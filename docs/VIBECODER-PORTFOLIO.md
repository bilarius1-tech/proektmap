# Портфолио вайбкодеров и AI-инженеров (Behance для AI-разработки)

## Концепция
Платформа ProektMap предоставляет каждому AI-инженеру и создателю цифровых продуктов (вайбкодеру) возможность вести профессиональное портфолио в стиле Behance. 

## Возможности
1. **Каталог работ сообщества (`/ai-workshop`)**:
   - Витрина запущенных ботов, SaaS-продуктов, веб-сервисов и автоматизаций.
   - Фильтрация по категориям и языкам.
   - Быстрый просмотр стека, AI-инструментов, времени разработки и автора.

2. **Страница кейса (`/ai-workshop/[slug]`)**:
   - Галерея скриншотов и превью продукта.
   - **AI-рецепт**: подробное описание процесса создания с помощью нейросетей (промпты, архитектура, агенты).
   - Ссылки на живой проект, репозиторий GitHub и Telegram-бота.
   - Интерактивная система «Респектов» (лайков) и шер в мессенджеры.

3. **Публикация работы (`/projects/new`)**:
   - Форма загрузки медиа, выбора AI-инструментов и стека.
   - Начисление +150 XP пользователю за опубликованный кейс.
   - Премодерация: новые работы проходят быструю проверку перед попаданием в публичный топ.

4. **Личный кабинет (`/dashboard`) и Профиль (`/profile/[id]`)**:
   - Редактор профиля: аватарка, позиционирование (headline), био, контакты (TG, GitHub, сайт), ключевой стек.
   - Управление своими работами, статистика просмотров и лайков.

5. **Каталог специалистов (`/specialists`)**:
   - Рейтинг вайбкодеров на основе XP, кейсов и статей в блоге.
   - Квалификационные уровни: Junior, Middle, Senior, AI-Архитектор.

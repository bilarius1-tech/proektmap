# Блог как граф знаний ProektMap

> **Статус:** 🎯 ориентир развития (14.08.2026)  
> **Не путать с:** текущим SEO-конвейером auto-publish (`src/lib/blog/seo-pipeline.ts`) — это **первый шаг**.  
> **Цель:** блог = накопительный актив, а не поток AI-рерайтов новостей.

---

## 1. Главная проблема AI-блогов (2026)

Большинство делают так:

```
Новость → AI пишет статью → SEO-статья → Публикация
```

Нужно так:

```
Новость
  → Определить сущность
  → Определить интент
  → Связать с графом знаний сайта
  → Создать материал
  → Усилить существующие страницы
```

**Новость — повод. База знаний — цель.**

---

## 2. Пример

Новость: *Cursor добавил новый AI Agent Mode*

| Обычный AI-блог | ProektMap |
|---|---|
| «Cursor выпустил Agent Mode…» | Сущность: Cursor Agent Mode |
| Статья живёт 2 дня | Есть страницы: Cursor, AI Agents, Vibe Coding, Blueprint AI-разработчика |
| После хайпа — мусор | Обновление карточки Cursor + AI Agents + статья + перелинковка |

```
Новость
  → обновление страницы Cursor
  → обновление страницы AI Agents
  → новая статья (если есть интент)
  → перелинковка в граф
```

---

## 3. Правило публикации

Публиковать статью **только если** выполняется хотя бы одно:

1. Появилась **новая сущность**  
2. Появился **новый поисковый интент**  
3. Можно **улучшить существующий кластер**

Иначе — **не публиковать**. Достаточно обновить существующую страницу.

| Пример | Решение |
|---|---|
| OpenAI выпустила новую модель | ✅ Публикуем — новая сущность |
| Ещё одно интервью про ChatGPT | ❌ Не публикуем — обновить карточку / кластер |

---

## 4. Типы материалов

| Тип | Что это | Срок жизни | Пример |
|---|---|---|---|
| **NEWS** | Новость | 1–7 дней | Cursor выпустил Agent Mode |
| **ENTITY** | Карточка инструмента / сущности | годы | Cursor, Claude Code, DeepSeek |
| **GUIDE** | Инструкция | месяцы–годы | Как использовать Cursor Agent |
| **BLUEPRINT** | Путь решения задачи | годы | Как создать SaaS с помощью AI |

Агент спрашивает не «написать статью?», а:

> **Какой объект базы знаний нужно обновить?**

---

## 5. Долгосрочные приоритеты SEO

| Тип | Вес | Почему |
|---|---|---|
| Blueprints | **40%** | ведут к действию и проектам |
| Guides | **30%** | вечнозелёный трафик |
| Entities | **20%** | якоря кластеров |
| News | **10%** | повод обновить граф, не ядро |

Через год–три трафик дают Blueprint и Guide, а не лента новостей.

---

## 6. Две метрики агента

### SEO Score (уже внедряется)

Проверка Title / Description / H1 / структура / FAQ / ссылки / уникальность.  
Порог публикации: **≥ 80**.

### Knowledge Value (цель)

| Вопрос | Баллы |
|---|---|
| Добавляет новую сущность? | +20 |
| Добавляет новый интент? | +20 |
| Улучшает кластер? | +20 |
| Создаёт новые связи? | +20 |
| Полезен через 6 месяцев? | +20 |

**Если Knowledge Value &lt; 60 — материал не писать.**

---

## 7. Финальное правило агента

> Ты не новостной журналист.  
> Ты архитектор базы знаний.  
>  
> Твоя задача не пересказывать новости.  
> Твоя задача увеличивать ценность графа знаний ProektMap.  
>  
> Каждый материал должен:  
> - отвечать на реальный запрос;  
> - усиливать существующие кластеры;  
> - создавать связи между сущностями;  
> - вести пользователя к инструменту, промпту, гайду или Blueprint;  
> - оставаться полезным после того, как новость потеряет актуальность.

Тогда блог — не «1000 AI-статей», а **связанная система** про AI-инструменты, агентов, промпты, проекты и вайбкодинг. Это сложно скопировать.

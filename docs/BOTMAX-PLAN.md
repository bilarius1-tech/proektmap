# Bot MAX — платформа ботов/мини-аппов для малого бизнеса (план)

> Бизнес-направление Алексея. Бренд: **Bot MAX**.
> Статус: решение принято 2026-09-30 — Telegram-боты/мини-аппы для СМБ (запись, напоминания, лояльность, доставка), дистрибуция через лиды konversus.
> Предыдущие версии плана (архив): `docs/VIBE-INCOME-TELEGRAM-BOTS.md`, `docs/VIBE-INCOME-BOOKING-SERVICE.md`.

## 0. Суть

**Платформа Telegram-ботов и мини-аппов для малого бизнеса: запись, напоминания, лояльность, доставка.**
Продаём подписку. Лиды берём из сервиса konversus (агент находит сайты ниш с почтой) и предлагаем автоматизацию холодной рассылкой.

## 1. Модули продукта

| Модуль | Задача | Приоритет |
|---|---|---|
| **Запись** | услуги, слоты, календарь, подтверждение/перенос | 🥇 MVP |
| **Напоминания** | за 24ч/3ч, follow-up «придёте?» | 🥇 MVP |
| **Лояльность** | виртуальная карта, бонусы, промо-рассылки | 🥈 фаза 2 |
| **Доставка** | каталог, корзина, статусы заказа | 🥈 фаза 2 |

**MVP = Запись + Напоминания.** Лояльность и доставку делаем только по запросам первых клиентов.

## 2. Архитектура — одна платформа (не «бот на клиента»)

```
Один Telegram-бот + один Mini App (Web App)
  └── тенант = бизнес (startapp=biz_123)
        └── Mini App открывает календарь/услуги конкретного бизнеса

Web-админка (PWA) для владельца:
  услуги, расписание, клиенты, уведомления, статистика

Сервис уведомлений:
  Telegram (в чат) → SMS (гарантия) → PWA-push (владельцу) → VK (фаза 2)

БД: одна на всех клиентов (SQLite на старте → PostgreSQL).
```

Фаза 2 — свой бот/токен на клиента (для брендовых ботов), внутри всё та же платформа.

**Стек:** Python + `aiogram 3` (бот) + Flask/FastAPI (Mini App + админка + API) + SQLite → PostgreSQL + APScheduler + ЮKassa.
**Деплой:** Nordic, PM2.
**Репо:** `botmax/` (отдельный проект, не внутри proektmap.ru).

## 3. Уведомления

| Канал | Кому | Стоимость | Решение |
|---|---|---|---|
| **Telegram в чат** | клиенту, записавшемуся через бота | бесплатно | ✅ Ядро |
| **SMS** | клиенту (гарантия, если не читает Telegram) | ~2–3 ₽/шт, квота в тарифе (напр. 200/мес) | ✅ В MVP |
| **PWA-push** | владельцу («новая запись», «отмена») | бесплатно | ✅ В MVP |
| **VK Mini App** | витрина для бизнесов с сообществом ВК | бесплатно | ⏳ Фаза 2 |

Правило: клиентам — **Telegram + SMS**, владельцу — **PWA-push**, VK — вторая витрина позже. PWA — та же web-админка, установленная на экран телефона.

## 4. Дистрибуция через konversus

1. Одна ниша на волну (бьюти → автосервисы → стоматологии → доставка/кофейни).
2. Собрать 50–100 сайтов ниши с почтой (агент konversus это умеет).
3. Персонализированное письмо-оффер: «Клиенты записываются сами в Telegram, бот напоминает — неявки падают. 15 минут — покажу на ваших услугах».
4. Демо → внедрение 5 000 ₽ + подписка 2 900 ₽/мес.

Правила холодной рассылки:
- слать с **отдельного домена** (не konversus.ru, не proektmap.ru);
- волнами 20–30 писем/день, письма персональные;
- цель первой волны — **ответ/демо**, не продажа; считать открытия и ответы.

## 5. Сайт Bot MAX (отдельный сервис)

Лендинг + PWA-админка для клиентов.

| Блок | Содержание |
|---|---|
| Hero | «Клиенты записываются сами. Бот напоминает. Вы не теряете деньги» |
| Демо-бот | QR/кнопка → настоящий бот с демо-салоном |
| Модули | Запись / Напоминания / Лояльность / Доставка (2 последних — «скоро») |
| Тарифы | 2 900 ₽/мес, внедрение 5 000 ₽ |
| Кейсы | «неявки −30%» (после первых 3 клиентов) |

**Оплата:** самозанятость (НПД) + ЮKassa. ИП — при обороте > 100–150k ₽/мес или найме.

## 6. Дорожная карта на 60 дней

| Фаза | Недели | Что делаем |
|---|---|---|
| 0. Фундамент | 1–2 | Репо `botmax/`, лендинг, отдельный домен + почта для рассылки, ЮKassa + самозанятость |
| 1. MVP | 3–4 | Бот + Mini App (запись), админка-PWA, напоминания Telegram+SMS, отзывы |
| 2. Первые продажи | 5–6 | 1 ниша, 50–100 писем, 1 бесплатный пилот, цель 3 оплаты |
| 3. Итерация | 7–8 | По запросам: лояльность ИЛИ доставка, VK-витрина, свой бот на клиента |

## 7. Метрики

- Продажи: 30 касаний → 5 демо → 3 оплаты (демо→оплата ≥ 50%).
- Продукт: неявки у пилота −30%; время внедрения ≤ 1 день.
- Деньги: 8 700 ₽/мес MRR + 15 000 ₽ разово к концу фазы 2.

## 8. Риски и как закрыть

| Риск | Решение |
|---|---|
| Telegram в РФ требует VPN | Платформа не зависит от одного канала: web-PWA + SMS в MVP, VK в фазе 2 |
| Холодная рассылка убивает домен | Отдельный домен, волны 20–30/день, персональные письма |
| «У нас уже YCLIENTS» | «Это не CRM, а запись в Telegram за 2 900 ₽, без обучения персонала» |
| Неявки не падают без предоплаты | Напоминания + follow-up; предоплата через ЮKassa — апселл |
| Распыление на 4 модуля | MVP = только Запись + Напоминания; остальное по запросам клиентов |

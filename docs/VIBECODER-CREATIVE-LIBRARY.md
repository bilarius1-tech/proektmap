Чтобы не утонуть в выборе:

| Tier | Название | Суть | Примеры |

### Performance / FPS Killers

Отдельный блок на галерее (`PERFORMANCE_KILLERS`): Three/p5 на мобиле без LOD, Lenis+RAF и батарея, pin-оргия ScrollTrigger, Vanta/particles на телефоне, splats без fallback, `prefers-reduced-motion`, дисциплина `requestAnimationFrame`.

## 2. Эталон: GSAP (полная карточка)

**ID:** `pm-lib-gsap`  
**Название:** GSAP  
**Одной строкой:** Профессиональный движок анимации для веба — от кнопок до scroll-фильмов.

**Категория:** Scroll / storytelling (+ UI motion)  
**Задачи:** scroll-сайт, сайт-фильм, product reveal, типографика в движении  
**Сложность:** medium  
**Стек:** любой JS (Next/React/Vue/чистый HTML)  
**Цена:** free (MIT)  
**Мобилка:** осторожно — сложные timelines упрощать на телефоне  

**Design DNA:**  
«Сайт ведёт себя как режиссёрская склейка: скролл = пульт камеры, не просто длинная страница.»

**Что умеет**
- Плавные анимации любых CSS/JS-свойств  
- **ScrollTrigger** — привязка анимации к скроллу (pin, scrub)  
- Timelines — сценарии «сначала A, потом B»  
- Совместимость с smooth scroll (часто + Lenis)  
- Уважение к `prefers-reduced-motion` (если заложить)

**Чего не умеет**
- Не рисует 3D-мир (для этого Three.js / Spline)  
- Не заменяет композицию и типографику  
- Не «сделает красиво сам» без Design Skill / раскадровки  

**Когда брать**
- Нужен wow-лендинг или «сайт-фильм»  
- Анимация должна быть синхронизирована со скроллом  
- Агент уже умеет React/Next, нужен сильный motion-слой  

**Когда не брать**
- Лендинг из 3 секций с лёгким появлением блоков → Motion или CSS  
- Нужна полноценная игра → Phaser / Pixi  
- Нужен интерактивный 3D-персонаж из редактора → Rive / Spline  

**С чем сочетается**
- **Lenis** — мягкий скролл  
- **SplitText / аналог** — анимация текста по буквам/словам  
- **Three.js / R3F** — 3D + scroll как камера  
- **Spline** — 3D-сцена проще, GSAP двигает UI вокруг  

**Альтернативы**
- Motion (ex Framer Motion) — UI внутри React-приложения  
- CSS scroll-driven animations — простые кейсы без библиотеки  
- Theatre.js — сложный timeline для креативных сцен  

**Типичные ошибки**
1. Анимировать всё подряд → шум, тошнота, лаги  
2. Забыть mobile / reduced-motion  
3. Сказать агенту «сделай красиво на GSAP» без раскадровки  
4. Путать GSAP с Three.js («3D на GSAP»)  

**Промпт для агента (копипаст)**

```text
Используй GSAP + ScrollTrigger в текущем проекте.

Цель: scroll-driven секция (сайт-фильм), не декоративный шум.

Сделай:
1) раскадровку 3–5 битов (что происходит на % скролла);
2) pin ключевой секции при необходимости;
3) scrub там, где движение привязано к скроллу;
4) уважение prefers-reduced-motion (отключить/упростить);
5) не ставь лишние библиотеки без нужды;
6) адаптируй под наш стек и существующие токены/компоненты.

Не копируй чужой код один в один — реализуй решение в архитектуре проекта.
Референс направления на ProektMap: /demo/scroll-film и docs/SCROLL-FILM.md.
```

**Демо / референс**
- https://proektmap.ru/demo/scroll-film  
- https://gsap.com  

**Связь с ProektMap**
- Канон: `docs/SCROLL-FILM.md`  
- Дальше: Design Skills (композиция) + эта библиотека (технология) + `/resheniya` (маршрут сборки)

## 3. Список 15 инструментов для MVP

Разнообразие по задачам, не 15 клонов анимации.

| # | ID | Название | Категория | Задача вайбкодера | Сложность | Вход |
|---|-----|----------|-----------|-------------------|-----------|------|
| 1 | `pm-lib-gsap` | **GSAP** (+ ScrollTrigger) | Scroll | Сайт-фильм, scroll-лендинг | medium | код + агент |
| 2 | `pm-lib-lenis` | **Lenis** | Scroll | «Масляный» скролл под GSAP/WebGL | easy | код + агент |
| 3 | `pm-lib-motion` | **Motion** (ex Framer Motion) | UI motion | Анимации UI в React | easy | код + агент |
| 4 | `pm-lib-lottie` | **Lottie / dotLottie** | Иллюстрации | Векторная анимация из After Effects / LottieFiles | easy | файл + агент |
| 5 | `pm-lib-rive` | **Rive** | Интерактив | Кнопки, маскоты, state machine | medium | no-code + runtime |
| 6 | `pm-lib-spline` | **Spline** | 3D (вход) | 3D-сцена без изучения Blender | easy–medium | no-code |
| 7 | `pm-lib-three` | **Three.js** | 3D | Свой WebGL-мир в браузере | hard | код + агент |
| 8 | `pm-lib-r3f` | **React Three Fiber** | 3D | Three.js «по-реактовски» | medium–hard | код + агент |
| 9 | `pm-lib-phaser` | **Phaser** | 2D-игра | Браузерная игра, квест | medium | код + агент |
| 10 | `pm-lib-pixi` | **PixiJS** | 2D-эффекты | Быстрый canvas/WebGL 2D, частицы | medium | код + агент |
| 11 | `pm-lib-p5` | **p5.js** | Генератив | Арт, скетчи, обучающие визуалы | easy–medium | код + агент |
| 12 | `pm-lib-anime` | **Anime.js** | UI motion | Лёгкие timelines без React | easy | код + агент |
| 13 | `pm-lib-theatre` | **Theatre.js** | Креативный timeline | Сложные сцены с визуальным таймлайном | hard | код + агент |
| 14 | `pm-lib-howler` | **Howler.js** | Звук | Музыка/SFX в вебе и мини-играх | easy | код + агент |
| 15 | `pm-lib-matter` | **Matter.js** | Физика 2D | Падения, коллизии, «живой» UI | medium | код + агент |

### Почему именно эти 15

- Покрывают **scroll / UI / 3D / игра / арт / звук / физика**  
- Есть **лестница входа**: Spline/Rive → GSAP → Three/R3F  
- Уже есть якорь на ProektMap: GSAP + Lenis в `/demo/scroll-film`  
- Не дублируют друг друга (Motion ≠ GSAP ≠ Phaser ≠ Three)

### Порядок написания карточек (контент)

1. GSAP (эталон) — **готово выше**  
2. Lenis, Motion, Spline, Rive — быстрые победы для вайбкодера  
3. Lottie, Phaser, Three, R3F  
4. Pixi, p5, Anime, Theatre, Howler, Matter

## 5. Критерий успеха MVP (контент)

MVP этой библиотеки успешен, если человек:

1. Открыл каталог и понял **без программистского жаргона**  
2. Выбрал 1–2 инструмента под задачу  
3. Скопировал промпт агенту  
4. Получил заметно менее «шаблонный» результат, чем «сделай красивый сайт»

Не цель MVP: 100 карточек, marketplace, CLI.

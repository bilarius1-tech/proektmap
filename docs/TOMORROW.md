## Решение по развитию (согласовать с Алексеем)

### 1. Отдельные страницы карточек `/avito/[slug]` — пока НЕ делать
Дадут: SEO long-tail, место под обзор/скриншоты, ссылки из блога.
Не дадут сразу: трафик без контента на каждой странице.
**Когда да:** после 40–50 карточек или когда пишем обзоры. Сейчас каталог-хаб выгоднее.

### 2. Кнопка «+ Добавить» + модерация — позже, лёгкий вариант
Сейчас админка под каталог **не нужна**: проще править `data.ts`.
Ближайший лёгкий шаг: форма «Предложить инструмент» → Telegram Алексею (как `/blog/suggest`). Без Prisma.
Админку + очередь модерации делать, когда заявок станет много (раз в неделю не успеваешь руками).

### 3. Master-list
Сохранить заметки Алексея в `docs/AVITO-MASTER-LIST.md` — очередь проверки, не публичный рейтинг.

### 4. Chrome Web Store
Найти точные URL AvToolsPro и LikeStats; заменить поиск на прямые ссылки.

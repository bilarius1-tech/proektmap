## Что такое Hub Page

**Hub Page (Хаб-страница)** — полноценная информационная страница-экосистема вокруг одной темы. Объединяет:

1. **Образовательный контент** — что это, как работает, зачем нужно
2. **Пошаговое руководство** — от нуля до результата
3. **Подводные камни** — типичные ошибки новичков
4. **Глоссарий через <Term />** — все технические термины с tooltip'ами
5. **Связанные сущности из БД** — Blueprint, AI Tools, Solutions, Skills
6. **FAQ** — часто задаваемые вопросы с раскрывающимися ответами
7. **CTA** — призыв к действию (пройти Blueprint, купить Pro)

---

## Структура страницы (секции сверху вниз)

```
1. HERO — тёмный градиент, иконка, заголовок, CTA-кнопки
2. Что такое [Тема] — объяснение + сценарии использования
3. Как создать/начать — пошагово (StepCard'ы)
4. Подводные камни — сетка PitfallCard
5. Почему [Тема] — 4 причины (ReasonCard)
6. Blueprint (если есть) — этапы с иконками
7. Готовые решения — карточки Solution
8. AI-инструменты — карточки AITool
9. Навыки + Глоссарий — две колонки
10. FAQ — раскрывающиеся <details>
11. CTA — финальный призыв
```

## Компоненты (переиспользуемые внутри page.tsx)

| Компонент | Назначение |
|-----------|-----------|
| `StepCard` | Пошаговая инструкция (номер + иконка + контент) |
| `StepContent` | Текст внутри шага |
| `PitfallCard` | Карточка подводного камня (жёлтая левая полоса) |
| `ReasonCard` | Причина/преимущество (иконка + заголовок + описание) |
| `ScenarioItem` | Сценарий использования |
| `FAQItem` | Раскрывающийся FAQ |
| `CodeBlock` | Блок с кодом (тёмный фон, моноширинный) |
| `InlineCode` | Инлайн-код |
| `SectionHeader` | Заголовок секции с иконкой и ссылкой «Все» |
| `Card` | Базовая карточка |
| `Stat` | Метрика (иконка + label + value) |
| `Tag` | Тег-лейбл |
| `Term` | Импорт из `@/components/glossary/tooltip-term` |

## Как создать новую Hub Page

### Шаг 1: Создать файл
```
src/app/[slug]/page.tsx
```

### Шаг 2: Скопировать структуру из /telegram/page.tsx
- Импорты: getDb, Link, Term, lucide иконки
- Компоненты-помощники в конце файла
- Секции — по необходимости (не все обязательны)

### Шаг 3: Добавить данные в БД
- Glossary terms (категория = тема)
- AI Tools (bestFor содержит ключевое слово)
- Solutions (isPublished + соответствующие)
- Skills (isPublished + соответствующие)
- Blueprint (если создаётся)

### Шаг 4: Прописать в меню
- menu_items: location='header', label='Тема', href='/slug'
- Или как child в родительский раздел (parentId)

### Шаг 5: Связать через Relations
- sourceType='blueprint', targetType='glossary'/'skill'/'aitool'/'solution'

## Принципы

1. **Образование важнее каталога.** Пользователь должен уйти с пониманием.
2. **Термины — с tooltip'ами.** Каждое незнакомое слово = `<Term term="..." />`.
3. **Код — только рабочий.** Каждый сниппет можно скопировать и запустить.
4. **Подводные камни — честные.** Не замалчивать проблемы, а предупреждать.
5. **FAQ — закрывает возражения.** Ответы на реальные вопросы новичков.

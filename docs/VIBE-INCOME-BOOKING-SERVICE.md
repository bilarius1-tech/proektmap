# Vibe-доход: сервис онлайн-записи для ниш — план на 30 дней

> Бизнес-направление Алексея. Цель: первые деньги на вайбкодинге через продукт «сервис записи для малого бизнеса».
> Статус: план скорректирован 2026-09-30 — Telegram убран из основы (в РФ требует VPN), канал: web + WhatsApp.
> Предыдущая версия плана (Telegram-бот): `docs/VIBE-INCOME-TELEGRAM-BOTS.md` (архив).

## 0. Суть бизнеса одной строкой

**Веб-страница записи, которая сама записывает клиентов, напоминает о визите в WhatsApp и собирает отзывы.**
Продаём как подписку малому бизнесу, которому не нужен большой CRM (YCLIENTS), но надоело терять клиентов на звонках и неявках.

## 1. Почему не Telegram (важное решение)

- Telegram в РФ сейчас работает только через VPN → как основной канал для массового клиента **отпал** (клиент маникюра не будет включать VPN, чтобы записаться).
- Бьюти-мастера и салоны **уже живут в WhatsApp** — это их основной канал общения с клиентами.
- База сервиса — **веб-страница записи по короткой ссылке**: работает в любом браузере, без VPN, ссылку можно кинуть в WhatsApp, Instagram, VK, Авито.
- Напоминания и отзывы — **через WhatsApp** (Green API).
- VK Mini App — вторая волна. SMS — резерв. Telegram — опция для тех, у кого он работает (или зарубежных клиентов).

## 2. Юридическое и платежи

| Вопрос | Ответ |
|---|---|
| Нужно ли юрлицо, чтобы создать сервис? | Нет |
| Как принимать платежи (подписка 2 900 ₽/мес)? | **Самозанятость (НПД) + ЮKassa**. Регистрация в «Мой налог» за 10 минут. Налог 4% с физлиц / 6% с юрлиц |
| Когда понадобится ИП? | Оборот > 100–150k ₽/мес, наём сотрудников, работа с крупными юрлицами |
| Комиссия ЮKassa | ~3% за платёж |

**Вывод:** на старте ни ИП, ни ООО не нужны. Самозанятость + ЮKassa закрывает схему «внедрение + подписка».

## 3. MVP (первая неделя)

**Обязательный минимум:**
1. Веб-страница записи: услуги, длительность, цена, рабочие часы, календарь слотов.
2. Админ-панель: услуги/часы, клиенты, отзывы (простой HTML на Flask).
3. Подтверждение / отмена / перенос по ссылке или кнопкам в WhatsApp.
4. **Напоминания за 24 ч и 3 ч в WhatsApp** (главная ценность — неявки).
5. Отзыв после визита: ссылка → 1–5 ⭐ + текст → админу в WhatsApp/панель.

**НЕ строим в MVP:** предоплату, мульти-мастеров, VK Mini App, каталог с фото, интеграции. Это фаза 2.

**Стек:** Python + Flask (страница записи + админка) + SQLite + APScheduler + Green API (WhatsApp, по HTTP).
**Деплой:** Nordic, PM2.

**Структура проекта:**
```
booking-service/
  app.py            # Flask: страница записи + админка
  services/         # slots, db, notify (whatsapp)
  templates/        # booking.html, admin.html
  data/service.db
```

**Что отдать агенту:** весь код по ТЗ выше. **Что делать руками:** тексты сообщений, ссылки, визуал — это и есть продукт.

## 4. Цены и оффер

| Позиция | Цена |
|---|---|
| Внедрение (настройка под клиента) | **5 000 ₽ разово** |
| Подписка | **2 900 ₽/мес** (до 2 мастеров, безлимит записей) |

Оффер: *«Клиент записывается сам по ссылке, напоминания приходят в WhatsApp — неявки падают, отзывы собираются сами. Внедрение за 1 день, без обучения персонала.»*

Первый пилот — **бесплатно** в обмен на отзыв и кейс.

## 5. Первые клиенты: откуда брать без рекламы

1. **Telegram/ProektMap** (аудитория, у кого Telegram работает): пост «ищу 3 пилотных мастера бьюти — бесплатно на месяц».
2. **Авито → Услуги**: объявление «Онлайн-запись для салонов и мастеров — клиенты записываются сами».
3. **WhatsApp-чаты мастеров** (бьюти-сообщества) и группы ВК: барберы, nail-мастера, косметологи.
4. **Прямой обход**: 20 салонов/барбершопов — лично или сообщением в WhatsApp.
5. **Партнёры**: SMM-щики и таргетологи, ведущие салоны — 20% с внедрения.

**Скрипт для обхода:**
> «Здравствуйте! Увидел вашу страницу — запись у вас через звонки/WhatsApp. Я делаю онлайн-запись: клиент сам выбирает время по ссылке, напоминания приходят автоматически в WhatsApp, отзывы собираются сами. Неявки падают. Могу за 15 минут показать на ваших услугах — бесплатно. Интересно?»

## 6. План на 30 дней

| Дни | Что делаем | Результат |
|---|---|---|
| 1–7 | Агент строит MVP, Алексей пилит тексты/визуал | Рабочий сервис на Nordic |
| 8–10 | 1 пилот бесплатно (мастер маникюра/барбер) | Боевой кейс |
| 11–14 | Пост в Telegram + 5 объявлений на Авито + 10 сообщений в чаты | Первые заявки на демо |
| 15–21 | Демо (15 мин на их услугах), обход 20 салонов | 5 демо → 3 оплаты |
| 22–30 | Внедрение 3 клиентов, кейс «до/после» по неявкам | **8 700 ₽/мес MRR + 15 000 ₽ разово** |

**Метрики месяца:** 30 касаний → 5 демо → 3 оплаты (демо→оплата ≥ 50%); неявки у пилота −30%.

## 7. После 3 клиентов

1. **Фаза 2 фич**: предоплата через ЮKassa (апселл, цена до 3 900 ₽), мульти-мастер, VK Mini App.
2. **Кейсы → контент ProektMap**: каждый клиент = статья «как сервис снизил неявки на X%» → трафик → новые клиенты.
3. **Масштаб**: автосервисы (2-я ниша), затем конструктор сервисов записи.

## 8. Риски и как закрыть

| Риск | Решение |
|---|---|
| «У нас уже YCLIENTS» | «Это не CRM, а простая онлайн-запись за 2 900 ₽, без обучения персонала» |
| Green API — неофициальный WhatsApp API | Отдельный номер под сервис; при блокировке — Wazzup (официальный RU-провайдер) как запасной канал |
| Неявки не падают без предоплаты | Напоминания + follow-up «Вы придёте?»; предоплата — апселл со 2-го месяца |
| Нет времени на продажи | 1 час/день на обход; остальное — сервис сам |
| Клиенты просят кастом | Всё вне MVP — «в план, за доплату». Первых трёх не кастомить |

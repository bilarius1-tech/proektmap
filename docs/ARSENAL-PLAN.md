## 1. Видение и позиционирование

**Нейро каталог** (`/arsenal`) — это не «ещё одна свалка AI-инструментов».

Это **стеки под миссию**: готовые наборы 4–7 инструментов в понятном порядке «зачем → чем → в каком порядке → как понять, что готово».

| Роль в экосистеме | Раздел | Обещание |
|---|---|---|
| Центр действия | `/resheniya` | Готовый маршрут до результата |
| Стек под задачу | `/arsenal` | «Возьми этот набор и иди» |
| Справочник инструментов | `/ai-tools` | Карточки отдельных тулов |
| РФ / без VPN | `/russian-ai`, `/russian-ai-stack` | Локализация и доступность |
| Микросервисы | `/services` | Готовые внутренние лаборатории |
| Авито-контекст | `/avito` | Продавец и карточки объявлений |

**Мост к `/resheniya`:** арсенал показывает *чем* решать; готовое решение показывает *как дойти до результата по шагам*. Ссылки двусторонние, без дублирования смысла.

**MVP:** 10–12 арсеналов + ~90–110 отобранных инструментов. Полные 304 строки Excel — поэтапно, без SEO-фермы «страница на каждый тул ради индекса».

## 2. UX-принципы (профессионально, адаптивно, удобно)

1. **Одна задача на экран.** Хаб отвечает: «какая у тебя миссия?» Карточка арсенала — стек и порядок. Карточка инструмента — факты и ссылки.
2. **Поиск + фильтры обязательны** с первого MVP: по названию, категории Excel, тегу миссии, «локально / облако», «РФ-доступно».
3. **Мобильный first.** Карточки в одну колонку, фильтры в выдвижную панель, порядок использования — нумерованный список без горизонтального скролла.
4. **Курирование важнее полноты.** Лучше 100 сильных карточек, чем 304 тонких SEO-страницы.
5. **Честные статусы.** Если инструмент «Работает/Архив» или дубль — помечаем в UI, не прячем.
6. **Визуальная ясность.** Иконка миссии, 1 предложение «для кого», 4–7 тулов, Definition of Done, типичная ошибка — без дашборд-шума.

## 3. Информационная архитектура `/arsenal`

Подробности маршрутов и полей — в [ARSENAL-STRUCTURE.md](./ARSENAL-STRUCTURE.md).

```text
/arsenal                         → хаб: миссии + поиск + фильтры
/arsenal/[slug]                  → карточка арсенала (стек)
/arsenal/tools/[slug]            → карточка инструмента (опционально в MVP)
/arsenal?q=...&cat=...           → поиск / фильтр (query на хабе)
```

Данные сначала — статический TypeScript-массив (как `/resheniya/data`), позже при необходимости — Prisma. Не смешивать с legacy Blueprint и не хардкодить пункты меню в header.

# Голосовой проводник ProektMap (Voice Guide)

## 1. Концепция и архитектура

**Голосовой проводник** — это аудиосопровождение разделов платформы ProektMap. При первом входе в раздел пользователю деликатно предлагается прослушать краткую суть страницы (20–35 секунд) и получить быстрые целевые действия («Что сделать дальше?»).

### Главный инженерный принцип
Голосовой проводник **не делает онлайн-запросов к TTS во время визитов пользователей**. 
Все аудиофайлы генерируются **заранее** на этапе сборки/разработки и сохраняются в `/public/audio/guides/*.mp3`. 
Клиентский браузер воспроизводит готовый MP3 через нативный HTML5 Audio (`new Audio(...)`), что дает:
1. **Нулевую задержку (0ms latency)** для пользователя.
2. **Нулевую стоимость** при миллионах прослушиваний (10 000 посетителей слушают один статичный файл).
3. **100% стабильность** без риска падения внешних API.

## 3. Как добавить голосовой гид для нового раздела (Инструкция)

### Шаг 1. Добавить раздел в реестр `src/lib/voice-guide/guide-data.ts`
В объект `VOICE_GUIDES` добавьте запись для нового роута:

```typescript
"/my-new-section": {
  id: "my-new-section",
  route: "/my-new-section",
  title: "Заголовок раздела",
  badge: "Категория",
  durationSec: 30, // примерная длина в секундах
  rawScript:
    "Текст для чтения пользователем на экране (субтитры). Содержит обычные термины: ProektMap, SaaS, AI, Next.js, API.",
  voiceScript:
    "Текст для диктора с фонетической нормализацией: ПроектМэ́п, са́ас, эй-а́й, Некст джи-э́с, эй-пи-а́й.",
  audioSrc: "/audio/guides/my-new-section.mp3",
  nextActions: [
    { label: "Целевое действие 1", href: "/my-new-section/start", primary: true },
    { label: "Смотреть каталог", href: "/resheniya" },
  ],
},
```

### Шаг 2. Сгенерировать MP3-файл
Выполните команду в терминале:
```bash
npm run voice:guides
```
Скрипт автоматически возьмет `voiceScript`, обратится к Yandex SpeechKit (или Edge-TTS), синтезирует голос Алёны и сохранит файл в `public/audio/guides/my-new-section.mp3`.

*(Если нужно сгенерировать через Microsoft Svetlana Neural: `npm run voice:guides:edge`)*.

### Шаг 3. Проверить билд и работу
```bash
npx next build
```
При заходе на страницу `/my-new-section` виджет автоматически подхватит аудиофайл по текущему `pathname`.

## 5. Тарификация и лимиты Yandex SpeechKit

1. **Модель оплаты:** Pay-as-you-go (оплата за фактическое число символов).
2. **Стоимость:** ~0,18–0,24 ₽ за 1 000 символов (один 30-секундный гид стоит **меньше 10 копеек**).
3. **Гранты и бесплатный порог:** Всем новым аккаунтам Yandex Cloud дается бесплатный стартовый грант (до 4 000 ₽ на 30–60 дней), в рамках которого можно сгенерировать тысячи аудиогидов бесплатно.
4. **Важно:** Поскольку мы генерируем файлы **один раз в MP3**, расход лимитов происходит **только при вызове `npm run voice:guides`**, а не при визитах пользователей на сайт.

# STRATEGY.md — Стратегический разбор (сессия 30.07.2026)

## Российский контекст: боли пользователей

| Боль | Возможность |
|------|-------------|
| Western AI заблокирован или требует VPN + ино. карту | Гайд «Российский AI-стек»: замена ChatGPT/Cursor |
| Telegram — платформа №1 (чаты, каналы, боты, платежи) | Blueprint «Telegram Bot» — золотая жила |
| Все хотят зарабатывать с AI | Схемы монетизации, партнёрки, фриланс |
| Vercel/Stripe/AWS недоступны без карт | Импортозамещение: Beget, TimeWeb, Selectel, ЮKassa |
| Нет социального доказательства | Витрина проектов, построенных на платформе |

## Текущее состояние проекта

- Next.js 16 + Prisma 7 + PostgreSQL + Tailwind + PM2
- 3 активных Blueprint: Корп.сайт (710 XP, 40 решений), SaaS (445 XP, 21), Игра (350 XP, 19)
- AI-Архитектор, Квест «Быстрый старт» (8 шагов)
- Блог + AI-автопубликация, RSS, комментарии, лайки/закладки
- Глоссарий (94 термина), Каталог AI-инструментов/MCP/моделей
- Pro-подписка 300 руб/мес через ЮKassa
- 172+ коммита, активная разработка

## Топ-4 направления (оценка сессии)

### 1. Blueprint «Telegram Бот» — максимальный охват
Telegram в России = экосистема №1. Боты заменяют сайты для многих бизнесов.
Путь: идея → aiogram/grammy → БД → ЮKassa → публикация.
Низкий порог входа, мгновенный результат, огромный рынок фриланса.

### 2. Гайд «AI без VPN: Российский стек»
Замена: ChatGPT→YandexGPT/GigaChat, Cursor→локально, Stripe→ЮKassa, Vercel→Beget.
Вечнозелёный SEO-контент под санкционный запрос. Трафик на годы.

### 3. Витрина проектов (Social Proof)
/showcase — реальные проекты пользователей. Скриншоты, отзывы, геймификация.
Новичок видит «это работает, я тоже смогу» → конверсия в регистрацию и Pro.

### 4. Партнёрская витрина + AI-фриланс
/earn — как зарабатывать с AI. Реферальные ссылки, схемы заказов.
Доска объявлений «Ищу AI-разработчика».

## Решение: Telegram Bot MAX — якорный продукт

Не просто Blueprint, а раздел-экосистема /telegram/:
- Blueprint (6 фаз, 24+ решений)
- Готовые шаблоны ботов на GitHub
- Конструктор ботов (визуальный)
- Витрина проектов

Связка: SEO «AI без VPN» → Blueprint «Telegram Бот» → Регистрация → Pro.

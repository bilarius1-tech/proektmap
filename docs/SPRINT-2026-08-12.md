## Визуальное направление: «Картографический минимализм»

Отход от AI-SaaS шаблона. Опора на `/demo/swiss` и `/sandbox`.

| Было (AI-шаблон) | Станет (своё) |
|---|---|
| AnimatedHero + blobs | Типографика + сетка, без декоративной анимации |
| Pills «⚡ Конструктор» | Uppercase-лейблы, 11px, letter-spacing |
| Карточки с radius + тенью | Swiss-grid: `gap: 1px`, тонкие линии, radius 0 |
| «Создавайте с помощью ИИ» | «Карта роста.**»** — инженерный навигатор |
| Emoji в меню | Только Lucide |
| Фиолетовый `#8b5cf6` | Убрать; акцент — зелёный `#0FB880` + чёрный |
| Inter везде | **Montserrat** заголовки + **Inter** текст |

**Фирменный знак:** `Карта роста.` — точка после «роста» как якорь.

**Референсы внутри проекта:**
- `/demo/swiss` — типографика, сетка, характер
- `/sandbox` — bento, radius 0
- Graph / Universe — интерактив оставляем, blobs на главную не тащим

**Запреты:** blobs, emoji в UI, purple, pills, box-shadow, градиенты на hero.

# Нейро каталог V1 — первые 12 стеков

> Legacy code name: arsenal.

**Статус:** черновик для реализации (документы, не UI).  
**Источник имён инструментов:** Excel «АРСЕНАЛ НЕЙРОРАЗВЕДКИ (27.08.2026)» — только реальные названия из каталога.  
**План:** [ARSENAL-PLAN.md](./ARSENAL-PLAN.md)

Каждый арсенал = **миссия + 4–7 инструментов в порядке использования + Definition of Done + типичная ошибка**.

Общий объём инструментов в V1 (с пересечениями между стеками): ориентир **~90–110 уникальных** карточек на этапе 1.

## 1. `local-ai-pc` — Локальный AI на ПК

| | |
|---|---|
| **Для кого** | Кто хочет работать без облака / без утечки данных / при слабом VPN |
| **Миссия** | Поднять чат с LLM на своём компьютере за один вечер |

**Порядок использования**
1. **LLM Checker** — понять, какое железо и какие модели потянет ПК  
2. **Ollama** или **LM Studio** — поставить рантайм  
3. **Open WebUI** — удобный чат + файлы/RAG поверх Ollama  
4. **llama.cpp** — запасной лёгкий запуск на слабом железе  
5. **Pinokio** — ставить соседние AI-приложения без ручной возни  
6. **Jan** — альтернативный локальный рабочий стол с моделями  

**Definition of Done:** открыт чат с локальной моделью (например Llama 3 / Qwen), ответ приходит без облачного API-ключа.  
**Типичная ошибка:** сразу качать огромную 35B-модель на ноутбуке с 8 ГБ RAM.  
**Связи:** `/russian-ai-stack`, `/ai-tools`, позже `/resheniya` (приватный контур).

## 3. `vibe-coder` — Агент-кодер / вайбкодинг

| | |
|---|---|
| **Для кого** | Вайбкодер, junior AI-инженер, кто собирает сайты/приложения с агентом |
| **Миссия** | От идеи до рабочего кода с проверкой, а не «чат написал и развалилось» |

**Порядок**
1. **OpenCode** — открытый кодинг-агент по репозиторию  
2. **Superpowers** — план → код → тест → проверка  
3. **ECC** — планирование, ревью, поиск ошибок  
4. **Agent Skills** — готовые навыки/воркфлоу для кодинг-агента  
5. **Understand Anything** / **CodeGraph** — разобрать чужой или свой проект  
6. **Claudexor** — если уже в экосистеме Claude Code / Cursor / Codex  
7. **Easy-Vibe** (гайд) — если нужен учебный трек vibe coding  

**DoD:** есть репозиторий, агент внёс изменение, есть наблюдаемый проверочный шаг (тест/запуск/превью).  
**Ошибка:** просить «сделай весь SaaS» одним сообщением без DoD.  
**Связи:** `/resheniya`, `/vaibik`, `/ui-patterns`.

## 4. `mcp-agents` — Агенты, скиллы и рабочий контур

| | |
|---|---|
| **Для кого** | Кто собирает агента с навыками, памятью и доступом к файлам/браузеру |
| **Миссия** | Собрать полезного агента, а не коллекцию закладок |

**Порядок**
1. **whichllm** — выбрать модель под задачу  
2. **Hermes Agent** — базовый самообучающийся агент  
3. **Awesome Hermes Skills** / **Hermes Skills Hub** — набрать навыки  
4. **Open Interpreter** — агент, который реально трогает файлы и команды на ПК  
5. **Stagehand** или **Kimi WebBridge** — управление браузером агентом  
6. **Headroom** / **MemPalace** — экономия контекста и локальная память  
7. **Agent Reach** — доступ к открытому вебу без платных search API (этично, публичные источники)  

**DoD:** агент выполняет одну сквозную задачу (файл + поиск + итоговый отчёт) без ручного копипаста на каждом шаге.  
**Ошибка:** ставить 50 скиллов до первой успешной задачи.  
**Связи:** `/skills`, `/resheniya`, MCP-разделы сайта.

## 5. `voice-pipeline` — Голосовой конвейер

| | |
|---|---|
| **Для кого** | Кто делает озвучку гидов, подкастов, дубляж, транскрибацию |
| **Миссия** | Текст ↔ речь ↔ текст в предсказуемом пайплайне |

**Порядок**
1. **Faster-Whisper** (или Whisper Base) — речь → текст  
2. **Piper** или **Kokoro TTS** / **Supertonic** — локальный текст → речь  
3. **Qwen3-TTS** — если нужен русский и клонирование/дизайн голоса  
4. **Voicebox** или **VoiceStudio** — локальная студия (TTS + транскриб + клон)  
5. **GPT-SoVITS-Russian** — русскоязычный клон/синтез  
6. **Auphonic** — выровнять громкость/шум перед публикацией  
7. **ElevenLabs** — облачный запасной вариант качества (не обязателен)  

**DoD:** есть MP3/WAV озвучки + текстовая расшифровка исходника; можно вставить в страницу/видео.  
**Ошибка:** клонировать чужой голос без прав — в ProektMap только свой/лицензированный материал.  
**Связи:** `/services/voice-guide-builder`, Voice Guide, `/resheniya`.

## 7. `ethical-research` — Этичный ресёрч и мониторинг

| | |

**Порядок**

**DoD:** документ-сводка со ссылками на источники + список «чего не хватает».

**Связи:** `/blog`, `/resheniya`, `/ai-tools`.

## 12. `desktop-agent` — Агент на рабочем столе

| | |
|---|---|
| **Для кого** | Кто хочет, чтобы AI делал действия на ПК, а не только писал текст |
| **Миссия** | Безопасный контур «агент + файлы + браузер» с понятными границами |

**Порядок**
1. **Open Interpreter** — ядро: файлы и команды  
2. **Goose** — код, команды, тесты, файлы  
3. **QClaw** / **Kimi Work** — агент, выполняющий задачи на машине  
4. **Stagehand** — браузерные действия  
5. **HAPI** — удалённый контроль кодинг-агентов с телефона (осознанно)  
6. **Memanto** / **TencentDB Agent Memory** — память между сессиями  
7. **OpenHuman** — мультиагентность + автоматизации (для продвинутых)  

**DoD:** агент создал файл, выполнил команду и вернул отчёт; пользователь понимает, какие папки разрешены.  
**Ошибка:** давать агенту полный доступ к системе без песочницы и бэкапа.  
**Связи:** `/skills`, `/resheniya`, арсенал `mcp-agents`.

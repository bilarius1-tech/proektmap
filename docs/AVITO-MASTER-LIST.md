## Продуктовая рамка

Не рейтинг аналитики, а **карта авитолога**: задача → цепочка инструментов.

| Задача | Типичная цепочка |
|---|---|
| Найти клиентов | Парсеры → конкуренты → мониторинг новых |
| Разместить 1 000 объявлений | Подготовка данных → уникализация текста/фото → XML → автозагрузка → контроль позиций → аналитика |
| Отвечать быстрее | AI-чаты → автоответы → CRM |
| Понять нишу | Спрос → категории → конкуренты → цены |

**Правило наполнения:** не выкидывать нишевые/маленькие инструменты только потому что они не «бренды». Сильная фишка ProektMap — редкий инструмент под узкую задачу.

Цель базы: **100+** строк в очереди → карточки после проверки URL.

Формат карточки после проверки:  
`название → ссылка → раздел → подкатегория → free/freemium/paid → что умеет → расширение? → API? → для кого → комментарий → серая зона?`

## Порядок работы агента (без UX)

1. Брать пачку 10–15 из очереди выше.  
2. Проверить живой URL (curl / сайт).  
3. Заполнить поля формата.  
4. Только потом — карточка в `src/app/avito/data.ts`.  
5. Нишевые оставлять; мёртвые — в блок «отложено» с датой проверки, не удалять из master-list молча.

Следующая рекомендуемая пачка: **парсеры** (ParsingMaster → Web-Data-Extractor + Diggernaut + A-Parser) и **AI** (Intly / avChat / AvBot / Umnico / OkoCRM).

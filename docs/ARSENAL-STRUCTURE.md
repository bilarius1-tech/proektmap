# Нейро каталог — структура раздела

> Публичное имя: **Нейро каталог**. Legacy folder/URL: `src/app/arsenal`, `/arsenal`.

**Статус:** реализовано в MVP (этап 1).  
**План:** [ARSENAL-PLAN.md](./ARSENAL-PLAN.md) · **V1-стеки:** [ARSENAL-V1-STACKS.md](./ARSENAL-V1-STACKS.md)

---

## 1. Маршруты

| URL | Назначение | MVP |
|---|---|---|
| `/arsenal` | Хаб: миссии, поиск, фильтры, сетка арсеналов | Да |
| `/arsenal/[slug]` | Карточка арсенала (стек под миссию) | Да |
| `/arsenal/tools/[slug]` | Карточка одного инструмента | Желательно; можно отложить и ссылать на внешний сайт + позже `/ai-tools` |
| `/arsenal?q=&cat=&tag=` | Поиск/фильтр на хабе | Да |

**Не делать** отдельные URL на каждую категорию Excel (`/arsenal/voice` и т.п.) в MVP — достаточно фильтров. Категории — это грани, не страницы.

## 2. Хаб `/arsenal` — UX

### Первый экран
- Заголовок бренда/раздела: **Нейро каталог**
- Одна фраза: «Стеки AI-инструментов под задачу — не свалка ссылок»
- Поиск (мгновенный, по названию и «что умеет»)
- CTA-группа: «Смотреть арсеналы» / «Связать с готовым решением» → `/resheniya`

### Ниже
- Фильтры-чипы: миссия, категория Excel, локально/облако, РФ-доступно
- Сетка карточек арсеналов (не 304 инструмента сразу)
- Блок «Если нужен один инструмент» → ссылка на `/ai-tools`
- Блок «Нужен пошаговый маршрут» → `/resheniya`

### Мобильный
- Поиск всегда сверху
- Фильтры — кнопка «Фильтры» → bottom sheet
- Карточки в 1 колонку, крупный тап-таргет

## 3. Поля карточки **Арсенал**

| Поле | Обязательно | Пример |
|---|---|---|
| `slug` | да | `local-ai-pc` |
| `title` | да | Локальный AI на ПК |
| `mission` | да | Для кого и зачем (1–2 предложения) |
| `audience` | да | AI-инженер / продавец / вайбкодер |
| `tools[]` | да | 4–7 slug’ов инструментов **в порядке использования** |
| `orderHint` | да | Краткие шаги 1…N |
| `definitionOfDone` | да | Наблюдаемый результат «готово» |
| `commonMistake` | да | Типичная ошибка новичка |
| `relatedRoutes[]` | желательно | `/resheniya`, `/services/...`, `/avito` |
| `excelCategories[]` | да | Какие категории Excel покрывает |
| `priority` | да | sortOrder для хаба |
| `status` | да | draft / published |

Арсенал = **стек**, не категория. Одна категория Excel может входить в несколько арсеналов.

---

## 4. Поля карточки **Инструмент**

| Поле | Источник Excel | Примечание |
|---|---|---|
| `slug` | из имени | транслит/kebab |
| `name` | AI-инструмент | как в таблице |
| `category` | Категория | одна основная; доп. теги отдельно |
| `summary` | Что умеет | можно чуть сжать для UI |
| `website` | Сайт | внешняя ссылка |
| `download` | Скачать | GitHub / установщик |
| `excelStatus` | Статус | Работает / Архив |
| `tags` | куратор | local, cloud, rf, mcp, … |
| `arsenalIds[]` | куратор | в каких стеках участвует |
| `aiToolsSlug` | опционально | если уже есть в `/ai-tools` |

Дубли из Excel (6 имён) — **одна** карточка + примечание «встречалось в двух строках».

## 6. SEO и карта сайта (когда будет код)

Обязательства проекта (правило `sitemap-seo`):

1. Добавить в `SITE_TREE` (`src/app/sitemap/site-map-data.ts`):
   - «Нейро каталог» → `/arsenal`
   - при публикации динамических страниц — генерация в `src/app/sitemap.ts`
2. На каждом `page.tsx` — `metadata` / `generateMetadata` + `canonical`
3. Проверка: `npm run validate:sitemap`
4. **Не** плодить индексируемые orphan-страницы без ссылок с хаба
5. Приватные `/admin` не трогать

Приоритет SEO: хаб и карточки **арсеналов** выше, чем каждая карточка инструмента. Инструменты можно индексировать постепенно (этапы 2–9), не все сразу.

## 7. Меню

Пункты шапки/футера **только через БД** (`MenuItem`), редактор: https://proektmap.ru/admin/menu  

После появления живого `/arsenal`:

- Пункт меню: label `Нейро каталог`, href `/arsenal`, id `header-arsenal`, location `header`
- Скрипт-подсказка: `npx tsx --env-file=.env scripts/sync-header-menu.ts` (или API `/api/admin/menu`)
- **Запрещено** вшивать `<Link href="/arsenal">` в `header.tsx` поверх списка из БД

Voice Guide уже зарезервировал `/arsenal` в `guide-data.ts` — после MVP обновить сценарий аудиогида.

## 8. Связь с существующими разделами

```text
Пользователь хочет РЕЗУЛЬТАТ по шагам  →  /resheniya
Пользователь хочет ГОТОВЫЙ СТЕК тулов  →  /arsenal
Пользователь ищет ОДИН инструмент      →  /ai-tools
Пользователь в РФ / без VPN            →  /russian-ai + /russian-ai-stack
Нужна внутренняя лаборатория           →  /services
Контекст продавца Авито                →  /avito (+ арсенал listing-photo / seller-content)
Вайбкодинг / креатив                   →  /vaibik (+ арсенал vibe-coder)
```

**Правило перелинковки:** в арсенале — 1–3 релевантные внутренние ссылки в контексте миссии, не «облако из всего сайта».

| Сосед | Как не путать |
|---|---|
| `/ai-tools` | Справочник тулов; арсенал — сборки под миссию |
| `/russian-ai` | Каталог РФ-моделей/сервисов; арсенал `rf-stack` — практический набор |
| `/services` | Наши микросервисы (запуск внутри ProektMap) |
| `/resheniya` | Инженерный маршрут с DoD на каждом шаге |
| `/solutions` | Другая сущность (библиотека архитектур) — не смешивать |
| `/blueprints` | Legacy — не тащить в меню арсенала |

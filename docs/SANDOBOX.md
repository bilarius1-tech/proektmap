## Что такое Песочница

**Песочница** — это четвёртый столп экосистемы ProektMap (после Blueprint, AI Архитектора и Знаний). Это коллекция исследовательских Hub Pages — полноценных информационных страниц, которые отвечают на вопрос «А что вообще можно сделать с AI в России?»

Песочница ≠ каталог. Это образовательный контент, который ведёт пользователя от «я ничего не знаю» к «я понимаю и готов выбрать Blueprint».

## Hub Page — структура

Каждая Hub Page следует шаблону (см. `HUB-PAGE.md`):

1. **Hero** — крупный заголовок, подзаголовок, CTA-кнопки
2. **Что такое [Тема]** — объяснение + сценарии использования
3. **Как создать/начать** — пошаговые StepCard'ы
4. **Подводные камни** — сетка PitfallCard
5. **Сравнения/Таблицы** (вариативно)
6. **FAQ** — раскрывающиеся `<details>`
7. **CTA** — призыв к действию (Blueprint, Pro)

### Компоненты Hub Page (переиспользуемые)

| Компонент | Назначение | Файл |
|-----------|-----------|------|
| `StepCard` | Пошаговая инструкция (номер + иконка) | Внутри page.tsx |
| `PitfallCard` | Подводный камень (жёлтая полоса) | Внутри page.tsx |
| `ReasonCard` | Причина/преимущество | Внутри page.tsx |
| `ModelCard` | Карточка AI-модели с кодом | Внутри page.tsx |
| `FAQ` | Раскрывающийся вопрос-ответ | Внутри page.tsx |
| `ReplacementCard` | Замена западного сервиса на российский | Внутри page.tsx |
| `ToolDetail` | Детальная карточка инструмента | Внутри page.tsx |

## Как создать новую Hub Page

### Шаг 1: Создать файл
```
src/app/[slug]/page.tsx
```

### Шаг 2: Импорты
```tsx
import { getDb } from "@/lib/db/index";
import Link from "next/link";
import Term from "@/components/glossary/tooltip-term";
import { ... } from "lucide-react";
```

### Шаг 3: Структура
Скопировать из существующей Hub Page (например `/telegram/page.tsx`). Заменить контент.

### Шаг 4: SEO
```tsx
export const metadata = {
  title: "Заголовок для поисковиков",
  description: "Описание 150-160 символов",
  openGraph: { ... },
};
```

### Шаг 5: Меню
```js
// Через скрипт:
db.menuItem.create({
  parentId: sandbox.id,
  label: "Название",
  href: "/slug",
  sortOrder: N,
})
```

## Дизайн-система Песочницы

- **Цвета:** только CSS-переменные (`var(--color-bg-primary)`, `var(--color-accent)`)
- **Радиусы:** 0px (плоский дизайн)
- **Сетка:** плотная, gap: 0, разделители через `border`
- **Ховер:** `background: var(--color-bg-tertiary)`
- **Шрифты:** `var(--font-heading)` для заголовков, `var(--font-body)` для текста

# ТЗ — Копилка дизайна (`/kopilka`)

> Короткое ТЗ. Ветка: `feature/kopilka-design`.  
> Суть: быстрая полка ссылок на дизайн-фишки (анимации, секции, кнопки, фоны, CodePen и т.п.) с AI-описанием на русском.

## Зачем

Алексей постоянно встречает ресурсы для сайтов (CodePen, UI-киты, фоны, дашборды). Нужно за 10 секунд: выбрать категорию → вставить ссылку → получить компактную строку в таблице. Описание пишет DeepSeek (уже в системе), не руками.

Не путать с:
- `/ui-patterns` — внутренние секции ProektMap
- `/arsenal` / `/ai-tools` — глубокие карточки инструментов
- `/vibecraft` — гайд по вайбкодингу

Копилка = **кураторская витрина внешних ссылок**, в первую очередь про дизайн.

## URL и роли

| Что | Где |
|-----|-----|
| Публичная витрина | `/kopilka` |
| Админка | `/admin/kopilka` |
| API | `/api/admin/kopilka/*` |
| Добавление с фронта | только `role === admin` (сессия) |

Гости: смотрят и фильтруют. Админ: добавляет/правит/удаляет/меняет порядок.

## UX публичной страницы

1. Заголовок: **Копилка дизайна** + одна фраза («Фишки для сайтов: анимации, секции, кнопки, фоны — как CodePen, но с русским описанием»).
2. Чипы категорий (быстрый выбор).
3. Компактная интерактивная таблица/список строк:
   - favicon
   - название (короткое)
   - описание RU 1–2 предложения (от AI, правится)
   - красивая кнопка «Открыть» (external, `rel=noopener`)
4. Для админа на той же странице — панель «+ ссылка»: категория + URL → Enrich → сохранить.

Мобильно: те же строки, крупный тап на кнопку.

## Пайплайн Enrich

```
URL → fetch HTML (title, og:title, og:description, link[rel=icon])
    → favicon URL (или Google s2 fallback)
    → DeepSeek: 1–2 предложения на русском «что это и зачем вайбкодеру/дизайнеру сайта»
    → запись в БД (можно править до/после)
```

Fallback без AI: `og:description` / title. Без секретов на клиенте — только server API.

## Админка

CRUD категорий и ссылок:
- добавить / редактировать / удалить
- перемещение (`sortOrder` ↑↓)
- публикация on/off
- кнопка «Перегенерировать описание» (DeepSeek)

## Модель данных (Prisma)

```
DesignBankCategory  — slug, title, emoji?, sortOrder, isPublished
DesignBankItem      — categoryId, url, title, descriptionRu, faviconUrl,
                      sortOrder, isPublished, sourceMeta?
```

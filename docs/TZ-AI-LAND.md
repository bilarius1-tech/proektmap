## 3. Phaser / Agent constraints

**Обязательно:**
- Phaser 4 + официальные examples / Agent Skills
- Готовый platformer/top-down example → адаптировать, не писать физику/collision/камеры/tilemap с нуля
- Сцены Phaser, не React-анимации мира
- i18n для всего текста (UI, диалоги, задания, бейджи)
- Quest state machine: `intro → talk → challenge → result → reward → done`

**Запрещено агенту:**
- Свой движок / своя физика / свой tilemap-парсер
- Переписывать Phaser internals
- Свободный чат с моделью без рамки задания
- Сбор ПДн детей сверх аккаунта ProektMap
- Лидерборд, соцсеть, микросервисы

## 4. Уровень 1 — AI Forest

**Сеттинг:** лес, тропа, дом, робот-NPC у моста.  
**Игрок:** персонаж ходит (клавиатура / тач).  
**Сюжет:** мост закрыт. Робот понимает только точные команды. Нужно собрать правильный prompt → мост открывается.

**Режимы возраста (один мир):**
- 9–11: конструктор из карточек `[КТО] [ЧТО] [ДЛЯ КОГО] [КАК] [ОГРАНИЧЕНИЯ]`
- 12–15: тот же квест + вариант «почини сломанный prompt» (свободный ввод с лимитом)

**Без image gen на L1:** результат = текст/готовая реакция NPC + анимация (мост, XP, бейдж).

## 5. Список заданий (станции L1)

| # | ID | Механика | Чему учит |
|---|-----|----------|-----------|
| 1 | `meet-robot` | Диалог с NPC | AI — не волшебник, ему нужна точная команда |
| 2 | `build-prompt` | Собрать prompt из карточек | Структура хорошего запроса |
| 3 | `bad-vs-good` | Сравнить 2 ответа робота | Плохой prompt → плохой результат |
| 4 | `fix-prompt` | Исправить сломанный prompt (12–15; для 9–11 — упрощённый выбор) | Prompt Quest / Fix the Prompt |
| 5 | `catch-lie` | Робот «врёт» — выбрать, что проверить | Галлюцинации / проверка |
| 6 | `reward` | XP + бейдж «Штурман ИИ» | Прогресс, закрытие уровня |

Источники содержания (не код): Prompt Quest, AI Literacy / Education AI Skills, идеи ThinkRank (hallucination, prompt sensitivity) — только как механики.

## 6. Критерии «готово» (Definition of Done)

- [ ] `/quest/ai-land` открывается на проде, Phaser-сцена грузится
- [ ] Игрок ходит по AI Forest, коллизии/камера работают (на базе Phaser example)
- [ ] NPC + диалоги на русском из `locales/ru`
- [ ] Задания 1–6 проходятся end-to-end без тупиков
- [ ] Оценка prompt через backend ProektMap (успех/подсказка/повтор)
- [ ] Прогресс сохраняется (гость — localStorage; юзер — БД)
- [ ] Бейдж «Штурман ИИ» выдаётся при `done`
- [ ] Нет emoji-стены текста; нет «урока prompt engineering» вне игры
- [ ] Mobile: тач-управление или экранные кнопки
- [ ] Build + `pm2 restart proektmap` без ошибок

**Вне скоупа L1:** другие миры, генерация картинок, EN-локаль полностью, leaderboard, родительский кабинет.

# Контент-цех V2

> Обновлено: 25.09.2026

## Для Алексея — как это работает

**Автопилот** раз в день сам:

1. Смотрит матрицу спроса (дыры в ядре: вайбкодинг, агенты, обучение, Cursor, без VPN…).
2. Выбирает одну тему.
3. Пишет guide с «плохо → хорошо» и ссылкой на продукт.
4. Если качество ок — публикует в блог и пишет в Telegram.

**Авито не берёт** — это не ядро продукта.

### Включить

1. Открой https://proektmap.ru/admin/blog/settings  
2. Включи **«Автопилот поисковых активов»**  
3. Сохрани  
4. Можно нажать **«Запустить автопилот сейчас»** для проверки  

При включении старый сбор новостей из RSS **отключается**.

### Расписание

Cron раз в час проверяет: если час = настройке (по умолчанию 10:00 МСК) и сегодня ещё не бегал — пишет 1 пост.

Лимит: 1 актив в сутки (можно 1–3 в настройках).

## Фокус продукта

**Ядро:** AI-вайбкодинг в России + обучающие материалы.  
**Спутник (P3):** Авито / маркетплейсы — только клики, не очередь активов.

## Пайплайн

```
спрос → интент → поисковая задача → ценность ProektMap
  → страница → перелинковка → CTA → измерение
```

## Команды

```bash
npm run content:phase0       # матрица + инвентаризация
npm run content:publish-p0   # ручные P0 активы (upsert)
npm run content:autopilot -- --force   # автопилот сейчас
```

## Автоматизация

| Слой | Авто? |
|------|-------|
| Автопилот активов (матрица → guide) | **Да** — cron + рубильник |
| RSS news-фабрика | **Нет**, если автопилот вкл |
| 301 merge/stop | Нет — только рекомендации phase0 |
| GSC → лиды | Пока нет |

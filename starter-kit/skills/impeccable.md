# impeccable — безупречная полировка UI

Конспект для AI-агента. Источник: Anthropic. Применяется ПОСЛЕ того, как интерфейс
работает: финальная доводка деталей, по которым считывается качество.

## Чек-лист полировки

### Визуальная точность
- Выравнивание: пиксель-в-пиксель, никаких «почти по центру».
- Контраст всех текстов на всех фонах (включая hover и disabled).
- Радиусы и тени из UI-кита, не случайные значения.
- Иконки одного стиля и оптического размера (stroke, заливка, вес).

### Состояния
- Hover / focus / active / disabled есть у каждого интерактивного элемента.
- Focus виден с клавиатуры (не только мышью).
- Ошибки и успех — с текстом и цветом, не только цветом.

### Пустые и крайние случаи
- Пустой список → понятное empty-состояние с действием.
- Длинный текст → перенос/обрезка без поломки макета.
- Нет данных / ошибка сети / загрузка — у каждого свой экран или блок.

### Микрокопия
- Кнопки — глаголы действия («Оплатить», а не «Ок»).
- Ошибки объясняют, что сделать («Введите телефон в формате +7…»).
- Один стиль обращений: на «ты» или на «вы», но не вперемешку.

### Переходы
- Переходы 150–250 мс, только там, где помогают понять изменение.
- Уважение prefers-reduced-motion.

## Правила

- Полировка — после функциональности. Сначала работает, потом безупречно.
- Не добавляй новые фичи на этапе полировки — только детали существующего.
- Каждый пункт чек-листа — с наблюдаемой проверкой (глазами на экране/скриншоте).

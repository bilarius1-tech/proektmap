# web-design-guidelines — правила продакшн-интерфейсов

Конспект для AI-агента. Источник: Anthropic (навык frontend design). Применяй
на фазах `design` и `build` для любых интерфейсов.

## Главный принцип

Не «красиво вообще», а **ясно и уместно**: интерфейс решает задачу экрана,
а не демонстрирует декорации. Сначала структура и контраст, потом эстетика.

## 1. Типографика

- Максимум **2 семейства**: display для заголовков + text для основного текста.
- Иерархия размерами: 1–2 крупных заголовка на экран, не все сразу.
- Высота строки: 1.5–1.7 для текста, 1.05–1.15 для заголовков.
- Длина строки 50–75 символов; не растягивай текст на весь экран.
- Не использовать Inter «по умолчанию» без причины — шрифт должен нести характер.

## 2. Цвет

- Палитра ролями, не случайные HEX: primary / text / bg / border / success / error.
- Правило 60-30-10: 60% фон, 30% вторичный, 10% акцент.
- Контраст текста ≥ 4.5:1 (обычный), ≥ 3:1 (крупный).
- Градиенты — только осознанно, без фиолетово-синих «AI-переливов».
- Цвет не единственный носитель смысла: статусы дублируй иконкой/текстом.

## 3. Отступы и сетка

- Базовая сетка 4px/8px; ритм — кратный (8, 16, 24, 32, 48).
- Сгруппированное > разбросанное: связанные элементы ближе, секции — с явным зазором.
- Контейнер контента с максимальной шириной (обычно 720–1200px).
- Один визуальный якорь на экран — самая важная вещь должна быть самой заметной.

## 4. Компоненты и состояния

- Кнопки: одна главная на экран (primary), остальные secondary/ghost.
- У каждого интерактивного элемента: hover, focus, active, disabled.
- Пустые состояния (нет данных) — с текстом и подсказкой, не голый экран.
- Ошибки — рядом с полем и человеческим языком, не «Error 500».

## 5. Запреты (анти-AI-скуф)

- ❌ Карточки ради карточек, всё в бордерах и тенях.
- ❌ Одинаковые секции «иконка + заголовок + текст» подряд.
- ❌ Скругления всего подряд (radius 20px на кнопках и карточках).
- ❌ Стоковые «планеты/роботы/лампочки» иллюстрации.
- ❌ Анимация без смысла.

# AI Project Starter — стартовый шаблон проекта с AI-агентом

Этот шаблон ведёт тебя от сырой идеи до работающего проекта по 8 фазам.
Внутри — кодекс агента, 8 команд-фаз, дизайн-скиллы и заготовки документов.
Работает в **OpenCode**, **Cursor** и **Reasonix**.

> Старт — это не «напиши агенту: сделай классный SaaS». Старт — это шаблон,
> идея в `inputs/idea.md` и движение по фазам.

## Начало за 3 шага

1. **Положи свою идею** в `inputs/idea.md` (своими словами; нет идеи —
   возьми одну из `ideas.md`).
2. **Открой эту папку** в своей среде (OpenCode / Cursor / Reasonix).
3. **Запусти первую команду** и иди по фазам:

| Фаза | Команда | Результат |
|---|---|---|
| 1 | `brief` | `outputs/brief.md` — обогащённый бриф |
| 2 | `research` | `outputs/research.md` — конкурентный синтез |
| 3 | `prd` | `outputs/prd.md` — одностраничный PRD |
| 4 | `design` | `outputs/ui-kit.md` — визуальный язык |
| 5 | `setup` | git, стек, `.env.example`, README |
| 6 | `plan` | `outputs/plan.md` — план работ с критериями |
| 7 | `build` | код инкрементами (шаг → проверка → коммит) |
| 8 | `review` | `outputs/review.md` — приёмка и финальный отчёт |

## Как запускать команды в твоей среде

| Среда | Команды лежат | Как запустить |
|---|---|---|
| **OpenCode** | `adapters/opencode/.opencode/commands/` | скопируй папку `.opencode` в корень проекта → `/brief` и т.д. |
| **Cursor** | `adapters/cursor/.cursor/rules/` | скопируй папку `.cursor` в корень → открой правило в Agent |
| **Reasonix** | `adapters/reasonix/.reasonix/skills/` | скопируй папку `.reasonix` в корень → вызывай skill по имени |

Или просто открой нужный файл из `commands/` и попроси агента:
«Прочитай `commands/03-design.md` и выполни».

## Обновление адаптеров

Команды живут в одном месте — `commands/`. Адаптеры для сред — копии.
После правки команд запусти:

```bash
node scripts/sync-adapters.mjs
```

## Полные правила

Кодекс агента — `AGENTS.md`. Полный текст правил разработки — `docs/rules.md`.

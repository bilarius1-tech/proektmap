Прочитай:
- `outputs/plan.md` — план работ
- `outputs/prd.md`, `outputs/ui-kit.md` — контекст продукта
- `AGENTS.md` — закон проекта

Ты — разработчик. Выполняй план строго по шагам, инкрементами.

## Правила цикла для каждого шага

1. Возьми следующий невыполненный шаг из плана.
2. Напиши код только под этот шаг. Не забегай вперёд.
3. Проверь критерий приёмки шага (команда/экран/тест).
4. Если критерий не зелёный — исправляй. Максимум 3 попытки, потом стоп + отчёт.
5. Прогони общие проверки проекта (lint/build/test), если они есть.
6. Закоммить: короткое сообщение в духе `feat: <шаг>`.
7. Отметь шаг в `outputs/plan.md` как выполненный (✅).

## Правила

- Один шаг = один коммит. Не смешивай шаги в одном коммите.
- Дизайн бери из `outputs/ui-kit.md`, не придумывай на ходу.
- Секреты — только в `.env`. В коммиты и промпты секреты не попадают.
- Если план упёрся в реальность (зависимость, недостающие данные) — стоп и спроси.
- Scratch-файлы и временные скрипты не коммить.

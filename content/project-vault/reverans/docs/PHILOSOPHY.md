# PHILOSOPHY — Reverans

СКХГ «Реверанс» — цифровая платформа студии художественной гимнастики.

## Для кого

- **Родитель** — просто: договор и оплата без бюрократии  
- **Админ** — полный контроль: группы, дети, платежи, документы  
- **Педагог** — только свои группы и дети  

## Принципы

Простота · Прозрачность · Гибкость цен/скидок · Доверие (онлайн-договор + ТБанк)

## Границы MVP

Не строить «всё сразу»: сначала админ-учёт, потом кабинет родителя, потом эквайринг.  
Дизайн важен, но не блокирует рабочий функционал.

Источник детализации: `tz/outputs/`.

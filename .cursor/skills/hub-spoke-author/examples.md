# Куда класть новую ветку

Один пример = одна идея. Копируй `good` в задачу агенту.

## 1. Новый маршрут «CRM для мастера»

**Плохо.** Новый пункт шапки «CRM», блок на главной, страница `/crm` без связи с `/resheniya`.

Почему ломает: новичок снова видит десятую дверь. Маршрут без станции не является готовым решением.

**Хорошо.**

```text
Станция: Решения (header-resheniya)
Хаб: /resheniya
URL: /resheniya/crm-master
Дальше: skill resheniya-author
Меню: спица header-resheniya-crm под header-resheniya
SITE_TREE: группа start → дети «Готовые решения AI»
Главная: не трогать
Мост: если нужен стек — arsenal-resheniya-bridge
```

## 2. Новая утилита «сжатие фото»

**Плохо.** `/photo-compress` + корень шапки «Утилиты» + виджет на главной рядом со станциями.

Почему ломает: инструмент притворяется продуктом. Дублирует `/services`.

**Хорошо.**

```text
Станция: Инструменты (header-station-tools)
Хаб: /services
URL: /services/photo-compress
Данные: src/lib/services/data.ts
Меню: не отдельный корень; достаточно хаба «Микросервисы»
SITE_TREE: группа tools → дети «Микросервисы»
Если нужна в маршруте Авито — ссылка из шага /resheniya/avito-business
```

## 3. «Слой обучения» как раздел

**Плохо.** `/examples-layer` в шапке «Примеры», потому что «у нас теперь слой примеров».

Почему ломает: слой — свойство страницы, не ветка. См. `.cursor/rules/examples-teaching.mdc`.

**Хорошо.**

```text
Не раздел.
Добавить плохо→хорошо в данные существующего хаба
(/ai-skills, /resheniya/[slug], /ui-patterns/[slug]).
Voice guide — registry в src/lib/voice-guide/guide-data.ts, не пункт меню.
```

## 4. Новый UI-рецепт экрана

**Плохо.** `/hero-recipe` + пункт «Собрать» дублирует хаб, либо новый корень «Рецепты».

**Хорошо.**

```text
Станция: Собрать (header-station-build)
Хаб: /ui-patterns/recipes
Дальше: skill ui-pattern-author
Меню: не трогать — рецепт живёт внутри хаба
SITE_TREE: группа design → дети «Готовые секции и виджеты»
```

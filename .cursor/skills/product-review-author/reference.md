# Product Review Author — справка

## Доли контента (ориентир редакции)

| Поток | Доля | Смысл |
|--------|------|--------|
| Обзоры внутренних продуктов | ~40–50% | рост и перелинковка |
| AI-инженерия с правилами | ~40% | трафик и доверие |
| Редкие внешние новости | ~10–20% | только практика + ссылка внутрь |

Авто-новости (RSS) живут отдельно: квота `BLOG_AUTO_PUBLISH_DAILY_LIMIT` (по умолчанию 2/день), правила в `src/lib/blog/relevance.ts` и `seo-pipeline.ts`. Этот скилл — для **ручных/агентских обзоров продуктов**.

## Как освежить список продуктов

```bash
# Быстрый обзор дерева
rg -n "title:|href:" src/app/sitemap/site-map-data.ts | head -100

# Микросервисы
rg -n "slug:|title:" src/lib/services/data.ts | head -80

# Graphify
graphify query "SITE_TREE MICROSERVICES resheniya"
```

Ключевые хабы (проверь актуальность в SITE_TREE):

- `/resheniya` — готовые AI-решения
- `/services` — микросервисы
- `/avito` — лаборатория Авито
- `/vaibik` — миссия новичка
- `/skills`, `/prompts`, `/ai-tools`, `/sandbox`, `/ui-patterns`
- `/russian-ai`, `/ai-without-vpn`

Не включай `/blueprints` как активный продукт витрины.

## Формула (канон)

```text
кому → задача → как открыть → что сделать за 10 минут → типичная ошибка → ссылка
```

Запрет: вода, «революционный инструмент», текст без кликабельной ссылки на раздел.

## Пример угла: Микросервисы

**Кому:** селлер / AI-инженер / вайбкодер, кому нужна узкая утилита в браузере без бэкенда.

**Задача:** сделать одно действие за минуты (уникализировать фото, посчитать токены, собрать голосовой гид).

**Как открыть:** https://proektmap.ru/services → карточка нужного сервиса.

**10 минут:** открыть сервис → выполнить 2–3 шага из `howToUse` → получить файл/код/результат.

**Ошибка:** ждать «магии сервера» — микросервисы считают в браузере; большие файлы/вкладки могут мешать.

**Ссылки:** `/services/<slug>` + смежный `/resheniya/...` или `/avito`.

## Связь с новостями AI-инженерии

Если пост про внешнюю новость (Cursor, модель, MCP), а не про продукт ProektMap — не этот скилл. Используй правила авто-редакции:

1. Что изменилось для практика
2. Что сделать
3. Где на ProektMap (ссылка)

Без обязательного FAQ «ради SEO».

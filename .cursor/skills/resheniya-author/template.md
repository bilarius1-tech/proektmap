## Definition of Done этапа

Этап готов только если:

1. принято решение;
2. добавлен артефакт (≥ осмысленного доказательства);
3. все checks отмечены;
4. нет открытого блокера.

## Антипаттерны

- Этап «изучи теорию» без артефакта
- Проверка «я всё понял»
- Промпт «помоги подумать»
- Ссылка на весь сайт вместо 2–4 нужных хабов
- Финиш «проект почти готов» без внешнего сигнала
